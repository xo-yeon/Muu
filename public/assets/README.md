# Muu Assets Directory

이 디렉토리는 Muu 프로젝트에서 사용하는 정적 리소스들을 관리합니다.

## 구조

- `characters/`: 인간 유형별 도트 캐릭터 이미지 (PNG, SVG)
- `icons/`: 감정 태그, 날씨 아이콘, 시스템 아이콘 (SVG 권장)
- `images/`: 일반 배경 이미지, 일러스트 등
- `fonts/`: 프로젝트 전용 픽셀 폰트 파일

## 가이드라인

- **도트 스타일**: 모든 이미지는 픽셀 아트 스타일을 유지합니다.
- **이미지 렌더링**: 웹에서 표시할 때 `image-rendering: pixelated` 속성을 사용하여 도트 질감을 살립니다.
- **포맷**: 아이콘은 확장성을 위해 SVG를, 캐릭터는 도트 질감을 위해 PNG 또는 SVG를 사용합니다.
